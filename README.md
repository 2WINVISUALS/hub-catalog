# 2WIN VFX Hub - catalog

Read automatically by the 2WIN VFX Hub inside DaVinci Resolve.

- `catalog.txt` - products shown in the Hub's ADD-ONS & UPDATES tab
- `hub.txt` - latest Hub version, SHA-256 fingerprint and release notes
- `hub.lua` - the Hub itself (downloaded only when a customer clicks UPDATE)

Get the packs at the 2WINVISUALS store.
